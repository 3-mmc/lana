The demo runs Praat in this page and replays what real models returned for two readings of one sentence, in German and Georgian.

Phones from the signal

The phone tier is read off the acoustics by an IPA recogniser, with no pronunciation dictionary in the way. The word tier comes from a separate model.

So ანტარქტიკის comes out as ɑ n tʼ ɑ r kʼ tʼ i kʼ i s, ejectives and all, and the method works for languages that have no dictionary.

Praat underneath, in plain sight

Pitch, formants, intensity and the spectrogram are Praat's own, compiled to WebAssembly. Every argument is a field you can edit, and the page prints the commands it ran.

Tiers fill as it runs

Each tier has its own model, and results appear while the job is still going. A lane that is still being computed looks different from one that is empty.

Who is speaking

A speaker tier keys on the voice, not the words, so it needs no language code and runs alongside the recogniser.

Here the speaker changes from S1 to S2 at 6.04 s, and the silence between them is left unassigned.

Offline, on a laptop

The desktop app has recognition built in. Download a model once and the recording never leaves the computer.

This Dargwa sentence was transcribed in under six seconds on a laptop CPU: words by MMS, phones by ZIPA.

Models, stated plainly

Each model shows its tier, size and licence before anything downloads, and the files are checked against published checksums.

Three ways to run it

Every version supports hand annotation, TextGrid import from Praat or ELAN, and recording from a microphone. Annotations save as you work.

Built-in recognition

At least one model per tier runs on an ordinary laptop. Which word model to use depends more on the language than on model size. MMS loads an adapter for each language, so it gets the script right where Omnilingual has to guess.

On 40 held-out Common Voice recordings each, MMS made 10.1% character errors on Dargwa and 12.1% on Ossetian. Omnilingual made 38–85% errors on the same recordings, mostly because it wrote them in the wrong script.
