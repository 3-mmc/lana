# MMS for Lana

The scripts that make Lana's MMS shared part (`export.py`, `build.py`,
`assemble.py`, `widen.py`) moved, with their history, to
[3-mmc/lana-models](https://github.com/3-mmc/lana-models) under `mms/`.
That repo holds all model training, conversion and export work; this one
keeps only the code that runs the models.
